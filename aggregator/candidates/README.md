# Candidates

Tracking which Lean packages we are considering for inclusion in
`lean-pool`, along with the reasoning behind each decision.

## Layout

- `packages/` — one file per candidate package, holding the curated
  metadata and review status. The per-package files are the source of
  truth for everything in this directory.
- `raw_data/` — Reservoir manifest snapshots used as input.
  - `manifest_trimmed.json` is committed: a slim derivation of
    Reservoir's bundle (~3 MB) keeping only the fields needed for
    candidate selection.
  - `manifest.json` (gitignored) is the full ~50 MB Reservoir bundle,
    fetched on demand by the aggregator CLI when `--raw-output` points
    here.
